# FDMS BANGLADESH

Fertilizer Dealer Management System - Bangladesh  
**Course:** CSE 3292 (Software Development III)

---

## Technical Stack
- **Frontend:** React.js (Vite), Tailwind CSS, Lucide Icons
- **Backend:** Java (Spring Boot)
- **Database:** PostgreSQL

---

## Project Structure

```text
FDMS BANGLADESH/
├── documantation/   # Project documentation, SRS, ERD, and proposal
└── frontend/        # React client application (Vite + Tailwind CSS)
```

---

## Getting Started

### Frontend (React)
```bash
cd frontend
npm install
npm run dev
```
Runs locally at: `http://localhost:5173`
